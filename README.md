# Kratos

A dark, gamified fitness and nutrition tracker built with React, TypeScript, Tailwind CSS, Lucide icons, and Recharts.

## Features

- Persistent XP, levels, daily streaks, daily quests, food logs, workout history, and macro bonuses via `localStorage`
- Dashboard hub with quest progress, XP level bar, streak status, macro rings, and a 7-day nutrition chart
- Nutrition tracker with instant macro lookup for common foods plus custom macro entry
- Fitness tracker with Push/Pull/Legs routines, active workout timer, set logging, volume calculation, and completion rewards

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```
